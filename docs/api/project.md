# docs/api/

这里放「接口长什么样」的 JSON 例子（命名：`示例-简述.json`）。

| 文件 | 白话说明 |
|------|----------|
| `示例-创建分析请求.json` | 网页点「开始分析」时，发给后端的那一包数据长什么样 |
| `示例-查询任务响应.json` | 问「这个任务跑完了吗」时，后端回什么 |
| `示例-分析报告.json` | 分析成功后，报告里有哪些字段 |

**谁说了算：** 以后端 Pydantic 与 `contracts/openapi.json` 为准。本目录只覆盖核心 analyses 速查，不含全部 P1/P2 扩展接口示例。  
改接口时，记得例子、后端、前端要一起改，别各写一套。
