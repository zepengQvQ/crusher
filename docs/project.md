# docs/ — 文档怎么找

**先读根目录 [`README.md`](../README.md)，把项目跑起来。**  
下面按「你想干什么」选一篇就行，不用从整改清单从头啃。

## 我想……

| 目的 | 打开 |
|------|------|
| 启动 / 演示 / 测试 / 排错 | 根目录 `README.md` |
| Demo 支持啥、字段啥意思、用哪段样例 | [`demo-支持范围与样例.md`](demo-支持范围与样例.md) |
| 找代码、看一次分析怎么走（Java 同学） | [`开发地图-代码与请求链路.md`](开发地图-代码与请求链路.md) |
| 在编辑器里直接点发送试接口 | [`http/示例-分析接口.http`](http/示例-分析接口.http) |
| 对照「请求/响应长什么样」 | [`api/`](api/)；完整 schema 以 `contracts/openapi.json` 为准 |
| 让 Cursor / Agent 按编号改代码 | [`agent-改代码约定.md`](agent-改代码约定.md) |
| 本地 MCP（可选） | [`MCP-本地使用说明.md`](MCP-本地使用说明.md)；`make setup-mcp` / `make run-mcp` |
| 查已完成的历史任务单 | [`archive/`](archive/)（P0 / P1 / P2 清单归档） |

> P0 / P1 / P2 主链路均已完成。日常从 README 与本页进入；长清单只作归档查阅。

## 文件怎么命名的

| 文件 | 干什么 |
|------|--------|
| 根目录 `README.md` | 上手入口（怎么启动） |
| 各目录 `project.md` | 只说「这个文件夹放什么」 |
| 其它 `.md` | 文件名本身就是主题 |
| `archive/` | 已完成阶段的执行清单（考古用） |

看不懂英文缩写时，先看 [`开发地图-代码与请求链路.md`](开发地图-代码与请求链路.md) 末尾的「容易懵的词」。
