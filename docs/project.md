## 命名规则（现行）

| 类型 | 语法 | 例子 |
|------|------|------|
| 目录说明 | 固定 `project.md` | 本文件、`api/project.md` |
| 现行说明 | **`类别-简述.md`** | `约定-…` / `范围-…` / `地图-…` / `说明-…` |
| 接口示例 | **`示例-简述.json\|.http`** | `api/示例-分析报告.json` |
| 历史清单 | **`archive/阶段-简述.md`** | `archive/P2-智能分析正确性.md` |

类别只用：`约定`（怎么改代码）、`范围`（做什么/不做什么）、`地图`（代码在哪）、`说明`（可选能力怎么用）。  
文件名以中文为主；仅允许专有词：`Demo`、`MCP`、`Agent`、`P0`/`P1`/`P2`。  
新文档按上表命名，并在本页「我想……」加一行。

看不懂英文缩写时，先看 [`地图-代码与请求链路.md`](地图-代码与请求链路.md) 末尾的「容易懵的词」。
