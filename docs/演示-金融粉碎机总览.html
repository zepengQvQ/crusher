Crusher

把金融话术
说清楚。

粘贴条款或销售话术，得到通俗解释、关键参数，以及带原文证据的风险发现。

能力

少而准的功能面。

对外只宣称两类产品。其余能力围绕「读材料 → 分析 → 可信报告」展开。

体验

一次分析，一条主线。

粘贴或上传 → 识别产品 → 提交任务 → 轮询 → 报告或明确失败。材料可留在 IM 会话里。

架构

分层清楚，规则在中间。

HTTP 只接线。领域规则、证据与发布门禁留在 domain。LLM 出草稿，程序做硬门槛。

技术

Vue H5 · FastAPI · 契约对齐。

本机双进程启动，默认 Mock 可断网演示。接口、测试与知识库都有固定落点。

演示

五分钟说清楚。

正向样例 → 失败态必演 → 可选否定句防误报。默认 MOCK_MODE=true，不必填 Key。

小结

少说。有据。失败不装安全。

仅供学习与演示，不构成投资建议。本 Demo 不做用户适当性评估。
